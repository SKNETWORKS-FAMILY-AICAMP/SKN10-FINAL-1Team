# AWS EC2 인스턴스 생성 완벽 가이드 (Windows 환경) 🚀

이 가이드는 AWS 계정이 있다는 전제하에 EC2 인스턴스를 생성하는 과정을 단계별로 설명합니다.

## 🎯 사전 준비사항

### 1. AWS 계정 준비
- **AWS 계정이 없다면**: https://aws.amazon.com/ko/ 에서 계정 생성
- **결제 정보 등록**: 신용카드 또는 체크카드 필요
- **프리티어 대상**: 신규 계정은 12개월간 t2.micro 무료 사용 가능

### 2. 추천 인스턴스 사양
```
프리티어 (무료): t2.micro (1vCPU, 1GB RAM) - 소규모 테스트용
일반 사용: t3.small (2vCPU, 2GB RAM) - 소규모 프로젝트
권장 사양: t3.medium (2vCPU, 4GB RAM) - Django + Next.js 안정 운영
고성능: t3.large (2vCPU, 8GB RAM) - 다중 사용자 서비스
```

## 🚀 EC2 인스턴스 생성 단계

### 1단계: AWS 콘솔 접속
1. **브라우저**에서 https://console.aws.amazon.com 접속
2. **로그인** (AWS 계정 이메일과 비밀번호 입력)
3. **지역 선택**: 우측 상단에서 **"아시아 태평양(서울) ap-northeast-2"** 선택

### 2단계: EC2 서비스 접속
1. **서비스 메뉴** 클릭 (왼쪽 상단 햄버거 메뉴)
2. **"컴퓨팅"** 섹션에서 **"EC2"** 클릭
3. 또는 검색창에 **"EC2"** 입력 후 선택

### 3단계: 인스턴스 시작
1. **"인스턴스 시작"** 버튼 클릭 (주황색 버튼)
2. 또는 **"인스턴스 → 인스턴스 시작"** 메뉴 선택

### 4단계: AMI (운영체제) 선택 ⭐
```
✅ 권장 선택: Ubuntu Server 22.04 LTS
- 이름: Ubuntu Server 22.04 LTS (HVM), SSD Volume Type
- 아키텍처: 64비트 (x86)
- 가상화 유형: hvm
- 프리 티어 사용 가능 표시 확인
```

**선택 방법:**
1. **"빠른 시작"** 탭에서 찾기
2. **"Ubuntu"** 항목 찾기
3. **"22.04 LTS"** 버전 확인
4. **"선택"** 버튼 클릭

### 5단계: 인스턴스 유형 선택 ⭐
```
프리티어: t2.micro (1 vCPU, 1 GiB 메모리) - 무료
소규모: t3.small (2 vCPU, 2 GiB 메모리) - 월 $16
권장: t3.medium (2 vCPU, 4 GiB 메모리) - 월 $33
고성능: t3.large (2 vCPU, 8 GiB 메모리) - 월 $66
```

**선택 방법:**
1. 원하는 인스턴스 유형의 **라디오 버튼** 선택
2. **프리티어 사용 가능** 표시 확인 (신규 계정)
3. 첫 테스트라면 **t2.micro** 권장

### 6단계: 키 페어 생성 🔑
키 페어는 SSH 접속을 위한 보안 키입니다.

**새 키 페어 생성:**
1. **"새 키 페어 생성"** 클릭
2. **키 페어 이름** 입력: `my-django-key` (원하는 이름)
3. **키 페어 유형**: RSA 선택
4. **프라이빗 키 파일 형식**: .pem 선택 (Windows용)
5. **"키 페어 생성"** 클릭
6. **자동으로 .pem 파일 다운로드됨** → 안전한 곳에 보관!

**⚠️ 중요:**
- `.pem` 파일은 절대 잃어버리면 안 됩니다!
- 다른 사람과 공유하지 마세요!
- 백업을 만들어두세요!

### 7단계: 네트워크 설정 🌐
**기본 설정 사용 (권장):**
1. **VPC**: 기본값 유지
2. **서브넷**: 기본값 유지
3. **퍼블릭 IP 자동 할당**: **활성화** 확인 ✅

### 8단계: 보안 그룹 설정 🔒
보안 그룹은 방화벽 역할을 합니다.

**새 보안 그룹 생성:**
1. **"새 보안 그룹 생성"** 선택
2. **보안 그룹 이름**: `django-nextjs-sg`
3. **설명**: `Django Next.js Web Application Security Group`

**인바운드 규칙 설정:**
```
규칙 1: SSH 접속용
- 유형: SSH
- 프로토콜: TCP
- 포트: 22
- 소스: 내 IP (자동 감지) ✅

규칙 2: HTTP 웹사이트 접속용
- 유형: HTTP
- 프로토콜: TCP  
- 포트: 80
- 소스: 0.0.0.0/0 (모든 곳에서 접속 가능) ✅

규칙 3: HTTPS 보안 웹사이트 접속용
- 유형: HTTPS
- 프로토콜: TCP
- 포트: 443  
- 소스: 0.0.0.0/0 ✅

규칙 4: Django 개발 서버 (임시)
- 유형: 사용자 지정 TCP
- 프로토콜: TCP
- 포트: 8000
- 소스: 0.0.0.0/0 ✅

규칙 5: Next.js 개발 서버 (임시)
- 유형: 사용자 지정 TCP  
- 프로토콜: TCP
- 포트: 3000
- 소스: 0.0.0.0/0 ✅
```

**인바운드 규칙 추가 방법:**
1. **"보안 그룹 규칙 추가"** 클릭
2. 위 표의 각 규칙을 하나씩 추가
3. **"유형"** 드롭다운에서 선택
4. **"소스"** 설정 (내 IP 또는 0.0.0.0/0)

### 9단계: 스토리지 설정 💾
```
권장 설정:
- 크기: 20 GiB (기본 8GB에서 증가)
- 볼륨 유형: gp3 (또는 gp2)
- 루트 볼륨에서 종료 시 삭제: 체크 유지 ✅
```

**설정 방법:**
1. **"스토리지 구성"** 섹션 확장
2. **크기**를 8에서 **20**으로 변경
3. **볼륨 유형**: gp3 선택 (더 빠르고 저렴)

### 10단계: 고급 세부 정보 (선택사항)
대부분 기본값 유지, 필요 시 설정:
```
- IAM 인스턴스 프로필: 없음 (기본값)
- 종료 동작: 중지 (기본값)
- 종료 보호: 비활성화 (기본값)
- 세부 모니터링: 비활성화 (기본값)
```

### 11단계: 최종 검토 및 시작 🎯
1. **"요약"** 섹션에서 설정 내용 확인:
   ```
   ✅ AMI: Ubuntu Server 22.04 LTS
   ✅ 인스턴스 유형: t2.micro (또는 선택한 유형)
   ✅ 키 페어: my-django-key
   ✅ 보안 그룹: django-nextjs-sg
   ✅ 스토리지: 20 GiB gp3
   ```

2. **"인스턴스 시작"** 버튼 클릭 (주황색)

### 12단계: 인스턴스 시작 확인 ✅
1. **"인스턴스가 시작되었습니다"** 메시지 확인
2. **"모든 인스턴스 보기"** 클릭
3. 새로 생성된 인스턴스의 **"상태"**가 **"실행 중"**이 될 때까지 기다림 (1-2분)

## 📋 생성 완료 후 확인사항

### 1. 인스턴스 정보 확인
생성된 인스턴스를 클릭하여 세부 정보 확인:
```
중요 정보:
- 인스턴스 ID: i-1234567890abcdef0 (예시)
- 퍼블릭 IPv4 주소: 13.125.xxx.xxx (실제 접속할 IP)
- 프라이빗 IPv4 주소: 172.31.xxx.xxx
- 상태: 실행 중 ✅
- 키 페어 이름: my-django-key ✅
```

### 2. 다운로드한 키 파일 확인
```powershell
# 다운로드 폴더에서 키 파일 확인
ls ~/Downloads/*.pem

# 키 파일을 안전한 곳으로 이동
mkdir C:\AWS-Keys
move ~/Downloads/my-django-key.pem C:\AWS-Keys\
```

### 3. SSH 연결 테스트
```powershell
# PowerShell에서 연결 테스트
cd C:\AWS-Keys
ssh -i "my-django-key.pem" ubuntu@YOUR_EC2_PUBLIC_IP

# 처음 연결 시 "yes" 입력하여 호스트 추가
```

### 예상 비용 (서울 리전 기준)
```
t2.micro: 무료 (프리티어) 또는 월 $8.5
t3.small: 월 $15.2
t3.medium: 월 $30.4
t3.large: 월 $60.8

추가 비용:
- EBS 스토리지 (20GB): 월 $2
- 데이터 전송: 1GB/월 무료, 초과 시 $0.09/GB
```

### 비용 절약 팁
1. **사용하지 않을 때 인스턴스 중지**:
   ```
   인스턴스 선택 → 인스턴스 상태 → 인스턴스 중지
   ```

2. **프리티어 모니터링**:
   - AWS 콘솔 → 결제 → 프리 티어
   - 사용량 확인 및 알림 설정

3. **예산 알림 설정**:
   - AWS 콘솔 → 결제 → 예산
   - 월 $10 예산 설정 권장

## 🛠️ 다음 단계

EC2 인스턴스 생성이 완료되었다면:

### 1. PowerShell 스크립트로 자동 설정
```powershell
# windows-scripts 폴더로 이동
cd windows-scripts

# EC2 자동 설정 (Docker, Git 등 설치)
.\setup-ec2.ps1 -EC2_IP "YOUR_EC2_PUBLIC_IP" -KeyPath "C:\AWS-Keys\my-django-key.pem"
```

### 2. 프로젝트 배포
```powershell
# 프로젝트 업로드 후 배포
.\manage-ec2.ps1 -EC2_IP "YOUR_EC2_PUBLIC_IP" -KeyPath "C:\AWS-Keys\my-django-key.pem" -Action deploy
```

## 🚨 문제 해결

### SSH 연결 실패
```powershell
# 1. 키 파일 권한 설정
icacls "my-django-key.pem" /inheritance:r
icacls "my-django-key.pem" /grant:r "%USERNAME%":"(R)"

# 2. 보안 그룹 확인
# AWS 콘솔 → EC2 → 보안 그룹 → SSH (22번 포트) 확인

# 3. 인스턴스 상태 확인
# AWS 콘솔 → EC2 → 인스턴스 → "실행 중" 상태 확인
```

### 웹사이트 접속 불가
```
확인사항:
1. 보안 그룹에서 HTTP (80), HTTPS (443) 포트 허용 확인
2. Django/Next.js 애플리케이션이 정상 실행 중인지 확인
3. 방화벽 설정 확인 (ufw status)
```

### 예상보다 높은 요금
```
확인사항:
1. 인스턴스가 불필요하게 실행 중인지 확인
2. 스토리지 용량이 과도하게 큰지 확인  
3. 데이터 전송량이 많은지 확인
4. 스냅샷이나 다른 리소스가 생성되었는지 확인
```
